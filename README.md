# QuickWire

A lightweight Blender 5.2+ viewport utility for toggling mesh-object wireframe visibility in the Blender viewport.  Borrowed/evolved from Meshlogic's 2017 script but largely re-engineered and refined for Blender 5.2.0+

And also largely inspired from 3dsMax where hitting the F3 key toggles wireframe visibility in the viewport.  This should be bog-standard available in Blender via a keystroke (maybe it is already but I haven't found it yet).

No interface, no icons, no complexity; just hit the "\\" (backslash) key to toggle wireframe visibility for one, selected or all mesh objects.

## Features

- Toggle active object wireframe
- Toggle selected objects
- Toggle all visible geometry
- Optional All Edges synchronization

Installation:
1.  In Blender, go to Edit > Preferences > Addons.

2.  Press top-right dropdown arrow "Install from Disk"

3.  Navigate to and select QuickWire.py.

4.  The addon should now be listed and checkbox-enabled.

5.  Return to your scene and watch the fireworks fly as you toggle the wireframe visibility to your heart's delight.  It works on one or several or all mesh objects simply by using:

## Default Shortcuts

- `\` — Toggle the active geometry object.
- `Shift + \` — Toggle selected geometry objects.
- `Ctrl + \` — Toggle all visible geometry objects.
